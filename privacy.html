プライバシーポリシー

Sift メール（以下「Sift」）は、個人用のメールアプリです。このページでは、Sift が Google アカウントのデータをどのように扱うかを説明します。

1. 使う権限

Gmail を追加するとき、Sift は Google に次の権限を求めます。

  • https://mail.google.com/（Gmail のメールの読み取り・送信・整理。IMAP と SMTP で接続するために必要です）
  • openid・email・profile（どのアカウントを追加したかを表示するため）

2. データの使い方

受け取ったメールとアカウントの情報は、あなたの端末の中の Sift だけが、メールの表示・送信・迷惑メールの判定・返信のお知らせのために使います。開発者のサーバーや第三者に送ることはなく、広告にも使いません。Google から受け取ったデータの使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

3. 保存

メールのコピーとログインの情報（アクセス トークン）は、あなたの端末の中に暗号化して保存します。Sift からアカウントを削除すると、その端末に保存したデータも削除します。

4. アクセスの取り消し

Sift へのアクセスは、いつでも Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます。

5. お問い合わせ

GitHub の Issues からご連絡ください。

English summary: Sift requests access to Gmail (https://mail.google.com/, plus openid/email/profile) only to read, send and organize your mail with IMAP and SMTP. Data is processed and stored (encrypted) only on your own device, is never sent to the developer or third parties, and is not used for advertising. Sift's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time at myaccount.google.com/permissions.
